## v2.0.1 / V17

v2.0.1 removes automatic disk logging while preserving the validated V16 universal HDR path.

The exact public-release checksums are generated by GitHub Actions and included with the release as:

```text
SHA256SUMS.txt
```

This avoids documenting a checksum from a local test binary when the public package is rebuilt on the GitHub Windows runner.
